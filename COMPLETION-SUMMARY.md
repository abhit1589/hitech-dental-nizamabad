## 📞 Support & Maintenance

### How to Update Content
1. **Edit HTML files** — Open in any text editor (VS Code, Sublime, even Notepad)
2. **Update images** — Replace files in `assets/images/` folder
3. **Modify styles** — Edit `css/styles.css`
4. **Test locally** — Run `python -m http.server 8000` and visit localhost:8000
5. **Deploy changes** — Re-upload changed files to hosting

### Common Updates
- **Change phone number:** Update in all HTML files + js/main.js
- **Add new service:** Edit services.html, add new card following existing pattern
- **Update hours:** Search for "10 AM–9 PM" across files and replace
- **Add doctor:** Create new file in doctors/ folder following existing format

### Technical Support
If you need help with:
- Custom features (online booking, payment integration)
- Backend development (form submissions to database)
- Advanced SEO or marketing
- Content writing or photography

Consider hiring a web developer or digital marketing agency.
